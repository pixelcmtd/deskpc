Alphacool doesn't specify Steinhart-Hart coefficients, so we'll have to
calculate them using a CAS (GeoGebra in my case lmao).

0°C = 273.15K
25℃ = 298.15K
37℃ = 310.15K
50℃ = 323.15K

1 / T = A + B ln R + C (ln R)³
NSolve({
    1 / 298.15 = A + B * ln(10) + C * ln(10)^3,
    1 / 310.15 = A + B * ln(6.468) + C * ln(6.468)^3,
    1 / 323.15 = A + B * ln(4.157) + C * ln(4.157)^3
}, {A, B, C})
A = 0.0026843747396
B = 0.0002860477674
C = 9.00418217869e-7
